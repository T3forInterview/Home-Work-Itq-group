
### Процедура запуска
1. Запустить образ PostgreSQL командой **docker-compose up -d**
2. Сформировать пакет для выполнения командой **mvn clean package**
3. Запустить приложение командой **java -jar target/homework-1.jar**
4. Открыть страницу  в браузере **http://localhost:8080/swagger-ui/index.html#/**
